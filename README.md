⚡ Week 2 — Electric Vehicle Range Prediction using Machine Learning
Overview

This week’s task focuses on building an **EV Range Prediction Model** using real-world Electric Vehicle (EV) specifications data.
The model applies **Linear Regression** to estimate the driving range based on parameters like battery capacity, efficiency, and drivetrain configuration.

Objectives

* Understand and preprocess real-world EV data
* Train and test an ML regression model
* Integrate a chatbot-style interface (EVA) for interactive predictions

Dataset

**Name:** `electric_vehicles_spec_2025.csv`
**Records:** 265
**Features:** 16 (includes battery capacity, speed, torque, drivetrain, etc.)

Workflow

1️⃣ **Data Cleaning** — removed text noise, handled missing values, encoded categorical features
2️⃣ **Model Training** — Linear Regression model trained with 80–20 split
3️⃣ **Model Evaluation:**

* R² Score: **0.961**
* MAE: **15.47**
* MSE: **332.76**
  4️⃣ **Chatbot (EVA):**
  A simple assistant that predicts range from user inputs like:

You: Predict range for 65 kWh EV  
EVA: Estimated range ≈ 355.23 km ⚡

Tools & Libraries

Python, Pandas, NumPy, Scikit-learn, Google Colab

Results

✅ 96.1% model accuracy
✅ Successfully implemented conversational interface for EV range prediction
